## Selected work

**[Retail Rocket ELT Pipeline and Data Warehouse](https://github.com/0GregoryJ/retail-rocket-elt-pipeline)**
Built an ELT pipeline to ingest ~3M rows of retail event data and ~20M rows of product data into PostgreSQL with PySpark, modeled the data into a galaxy schema with dbt, defined a semantic layer on top of the marts, and exposed metrics, entities, and dimensions with Lightdash for self-serve visualizations.

**[Bay Wheels Operations Analysis](https://github.com/0GregoryJ/Bay-Wheels-Operations-Analysis)** — Tableau dashboard and executive summary on ~10.6M Bay Wheels trips (2024–2026). Covers station rebalancing, member vs. casual demand, and trip trends over time. Python pipeline from raw CSVs to summary tables for the dashboard.
