### Selected work

**[Greenhouse IoT Streaming Pipeline](https://github.com/0GregoryJ/greenhouse-iot-streaming-pipeline)** - Building an end-to-end real-time streaming pipeline for greenhouse sensor data. Events are transmitted over MQTT to a Raspberry Pi, buffered in SQLite for reliable delivery, and published to Kafka on AWS. A downstream consumer maintains live readings in Redis, exposed through FastAPI to a React dashboard.

**[Retail Rocket ELT Pipeline and Data Warehouse](https://github.com/0GregoryJ/retail-rocket-elt-pipeline)** - Built an ELT pipeline to ingest ~3M rows of retail event data and ~20M rows of product data into PostgreSQL with PySpark, modeled the data into a galaxy schema with dbt, and defined a semantic layer with Lightdash for self-serve analytics.

**[Bay Wheels Operations Analysis](https://github.com/0GregoryJ/Bay-Wheels-Operations-Analysis)** - Tableau dashboard and executive summary on ~10.6M Bay Wheels trips (2024–2026). Covers station rebalancing, member vs. casual demand, and trip trends over time. Python pipeline from raw CSVs to summary tables for the dashboard.
